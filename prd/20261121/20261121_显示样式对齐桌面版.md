# 显示样式对齐桌面版

## 1. 需求背景

桌面软件 MarkdownView（`D:\workspace\github-my\MarkdownView`，Tauri + 同款 Milkdown Crepe 7.22.3）沉淀了一套完整的 Typora Drake 排版契约；当前插件只有 `--crepe-*` → `--vscode-*` 的变量映射与零散样式，正文观感与桌面版差距明显。以桌面版显示效果为基准，优化插件的 md 显示（仅显示，不涉及编辑行为与布局决策）。

## 2. 需求内容

以下样式全部映射到 VS Code 主题变量，明暗主题自动跟随：

1. **排版基线**：正文 line-height 1.6、连字与抗锯齿。
2. **标题尺度**：h1–h6 = 2.25 / 1.75 / 1.5 / 1.25 / 1 / 1 rem（选择器需带 `.ProseMirror` 以压过 Crepe reset 的 em 尺度）；标题行首显示 H1–H6 级别角标，编辑模式显示、只读（预览）模式隐藏。
3. **节奏**：`--p-spacing: 0.8rem` 统一段落/列表/表格纵向间距；hr、图片圆角。
4. **引用块**：左边框 + 浅色底 + 右圆角（告警块由专属样式接管，需排除）。
5. **代码**：代码块圆角/底色/内边距/行高；行内代码底色/前景/圆角。
6. **表格**：th/td 内边距与字号、表头底色、斑马纹（注意 Crepe 表格块是单 tbody、表头行占第一个 child，斑马纹选择器需从 `2n+3` 起）。
7. **列表**：修复 Crepe 列表符号盒（固定 32px 高）与 1.6 行高正文的垂直对齐。
8. **告警块**：五种类型各自的左边框/标题色/浅色着色底；标题行含内联 SVG 图标（`createElementNS` 构建，`currentColor` 描边适配深浅主题，移植自桌面版 `alert.ts`）；alert schema `toDOM` 增加图标 + 标题行 + body 容器；因新结构会被粘贴/剪贴板往返重解析为内容，移除原 `parseDOM` 规则（与桌面版一致）。

**不移植**（维持插件既有决策或无对应能力）：正文宽度 clamp（PRD 20261030 已决策自适应全宽）、滚动条等应用级样式、脚注样式（插件无该节点）、`==mark==`（插件无解析插件，属死样式）、emoji / 原始 HTML 渲染（范围确认时排除）。

## 3. 验收标准

1. 亮/暗两主题下：标题尺度与角标、折叠块、引用块、五类告警（图标+标题+着色）、表格（表头/斑马纹）、代码与行内代码、列表对齐均正确渲染。
2. 角标仅编辑模式显示。
3. 既有功能不受影响：折叠块行为、Mermaid 面板、三态模式。
4. `pnpm run check`、`pnpm run package`、`git diff --check` 通过。
