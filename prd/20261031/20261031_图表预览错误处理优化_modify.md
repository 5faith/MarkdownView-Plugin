# 修改记录：图表预览错误处理优化

## 2026-10-31 — 保留旧图与错误状态条，编辑防抖调整

- 运行时验证：以本地 HTTP harness 在真实浏览器中对示例文档 34 个 mermaid 块逐个 `mermaid.parse`，全部类型在 Mermaid 11.17.2 可解析；`usecase-beta` 由 `usecase-diagram.ts` 翻译为 flowchart 渲染。确认 “Syntax error in text” 来自编辑过程中的中间态源码，与图表数量、类型支持无关。
- 渲染失败不再把错误文本写入预览区：保留上一次成功 SVG，在预览下方新增错误状态条（`.mermaid-diagram-error-strip`），按错误消息分类（“No diagram type detected” → 不支持类型；其他 → 语法有误），`title` 显示原始错误首行；渲染成功或源码清空时自动隐藏。
- 首次渲染即失败（无旧图）时，预览区占位文本从“图表将在滚动到可视区域后渲染。”改为“无法渲染图表预览。”，避免与错误状态条矛盾；文档中确实保存了无效源码时（编辑模式会实时写回），显示该状态属预期行为。
- 编辑模式源码面板打开时的渲染防抖从 250ms 提高到 800ms，且每次输入重置计时器（真防抖，连续输入不中途触发渲染）；外部变更保持 250ms。
- 计划中的“内置类型关键字清单”经运行时验证确认不必要（示例全部可解析），改为按错误消息分类，避免随 Mermaid 版本维护硬编码清单；示例文档无需标注不支持类型。
- 更新 README 与示例文档中的预览更新时机与错误行为说明。
