# 选中文字格式工具栏

## 需求

编辑模式下选中一段文字时，在选区上方弹出浮动格式工具栏（参考图2 Typora）：加粗（B）、斜体（I）、删除线（S）、行内代码（<>）、行内数学公式（Σ）、链接（🔗）；选区收起或点击其他位置时隐藏；选区命中已有格式时对应按钮高亮。

## 需求说明

- 触发：`selectionchange`（120ms 防抖）后，编辑模式、非空选区、DOM 选区与 ProseMirror 选区均落在编辑器文本块内（排除 CodeMirror 代码块与 Mermaid 面板、对话框打开时）→ 定位到选区矩形上方（空间不足时在下方）。
- 动作：`toggleStrongCommand` / `toggleEmphasisCommand` / `toggleStrikethroughCommand`（gfm）/ `toggleInlineCodeCommand`；Σ → Crepe Latex 特性的 `ToggleLatex` 命令（`commandsCtx.call`，选中文本转 `math_inline` 节点，序列化为 `$…$`）；链接 → 复用 `requestLink`（预填对话框 → `toggleLinkCommand { href }`，URL 校验同弹窗）。
- 按钮按下 `preventDefault` 保持编辑器选区不丢失；命令派发后按 `doc.rangeHasMark` 刷新各按钮 active 高亮（公式按选区内是否含 `math_inline` 节点判断）。
- 隐藏：选区收起、点击工具栏外、Escape、滚动、切模式、宿主更新。

## 验收标准

- 选中文字弹工具栏，6 个动作全部生效且回写正确（`**…**`、`*…*`、`~~…~~`、反引号、`$…$`、`[…](href)`）。
- 选区命中已有格式时按钮高亮；选区收起即隐藏；代码块/Mermaid 内选区不弹。
- `git diff --check` 通过。
