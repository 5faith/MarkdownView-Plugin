# 修改记录：编辑模式图表渲染修复与 NodeView 重构

## 2026-10-31 — ignoreMutation 修复与 mermaid-view 拆分

- 根因定位：NodeView 未实现 `ignoreMutation`，编辑模式下 `preview.innerHTML = svg` 等自管 DOM 变更被 ProseMirror 误读为文档变更（`registerMutation` 返回整节点范围并按 DOM 重解析），导致全部 mermaid 节点源码损坏并写回文档；只读模式不处理 DOM 变更故不受影响。
- 浏览器 harness（真实 webview bundle + `acquireVsCodeApi` shim + 本地静态服务）复现基线：编辑模式输入后 34 个图表源码全部损坏（mindmap 67 字符 → 仅剩首行，内容在相邻节点间错位）、SVG 全部丢失、损坏 markdown 写回；修复后同场景 0 损坏。
- 新增 `src/webview/mermaid-view.ts`：Mermaid 运行时加载、串行渲染队列与 LRU 缓存、可视区调度协调器、`mermaid_diagram` schema 与 NodeView 集中管理。
- NodeView 实现 `ignoreMutation`（`contentDOM` 之外的变更返回 true）与 `stopEvent`（源码面板折叠按钮不抢占编辑器焦点/选区）。
- 源码面板由 `<details>` 原生收起改为 header 按钮 + 内层 wrapper CSS 折叠（`visibility:hidden; height:0; overflow:hidden`），contentDOM 不再被 `display:none` 隐藏；外观与交互保持“▸/▾ Mermaid 源码”。
- `markdown-extensions.ts` 回归 remark 转换与告警/折叠/定义列表 schema 职责，mermaid 插件改为 `...mermaidDiagramPlugins` 引入；`main.ts` 改从 mermaid-view 导入 `configureMermaid`。
- harness 验证期间发现隐藏页面 rAF 暂停会阻塞可视区 pass（真实 VS Code webview 编辑时可见，不受影响），harness 以 rAF→setTimeout 兜底模拟可见环境完成验证。
