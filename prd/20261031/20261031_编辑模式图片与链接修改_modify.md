# 修改记录：编辑模式图片与链接修改

## 2026-10-31 — 点击拦截提升到 document 捕获阶段

- 真实 VS Code webview 中编辑模式普通点击链接仍跳转（harness 无法复现）：根因判定为事件时序——原拦截挂在 `#editor` bubble 阶段，VS Code 注入的 webview 宿主脚本/其他 document 级监听可能先执行，`preventDefault` 来不及。
- `src/webview/main.ts`：拦截改为 **document 捕获阶段**（`root.contains(target)` 限定编辑画布内），命中链接/图片即 `preventDefault + stopPropagation`，独占处理：编辑模式普通点击→弹窗、Ctrl/Cmd+点击→`openMarkdownHref`；只读模式点击→跳转链接/打开图片地址。原 bubble 处理器退化为仅收起弹窗。
- harness 全场景回归通过：编辑普通点击两类链接（含 `<username@gmail.com>` 自动链接）弹窗且零 openLink；Ctrl+点击链接×2、图片×1 各产生 openLink；只读点击链接/图片跳转且无弹窗。

## 2026-10-31 — 图片支持 Ctrl/Cmd+点击打开地址

- `src/webview/main.ts` 根级 click 处理新增非编辑指针分支：Ctrl/Cmd+点击（及只读模式 Ctrl+点击）图片时，经 `findImageNodeFromElement` 读取节点原始 `src` 并走 `openMarkdownHref`（http/https 外部打开、相对路径由宿主 `vscode.open` 打开，`data:` 由 provider 忽略）。
- harness 验证（用户实际源码 `* [超级链接](…)`、`* <username@gmail.com>`、远程图片）：普通点击链接/自动链接均弹窗不跳转；Ctrl+点击两条链接与图片均产生对应 `openLink`；弹窗按预期收起。

## 2026-10-31 — 交互确认：点击编辑、Ctrl+点击跳转

- 用户确认最终交互：编辑模式**点击**链接/图片弹出操作条，**Ctrl/Cmd+点击**才跳转；曾评估 hover 触发方案，未采纳未合入（代码已完全回退，类型检查与构建通过）。

## 2026-10-31 — 链接/图片操作条与 URL 校验

- `src/webview/main.ts`：
  - `requestValue` 增加可选 `validate` 回调：确认时校验失败 `preventDefault` 保持对话框打开并在 label 追加错误提示。
  - 新增 `validateLinkHref` / `validateImageSrc` / `validateHttpUrl` / `isForbiddenHost`：相对路径与 `#anchor` 放行，链接允许 `mailto:`、图片允许 `data:image/*`，http/https 校验 host（拒绝 localhost、环回、10/8、172.16-31、192.168/16、169.254/16、fc00::/7、0.0.0.0、.local），其余 scheme 拒绝。
  - 新增 `#link-image-toolbar` 浮动操作条（动态创建，定位复用 block-insert-menu 模式）：链接显示 href + 编辑/打开/移除；图片显示原始 src（读 PM 节点属性，避免被 `proxyDomURL` 改写的 DOM src）+ 更换地址。点外部/Escape/滚动/切模式/宿主更新时隐藏。
  - 根级 click 拦截改造：编辑模式点击链接/图片弹操作条不跳转；Ctrl/Cmd+Click 与只读模式保持 `openMarkdownHref`（锚点滚动或 openLink）。
  - 新增 `findImageTargetInDoc`（posAtDOM 解析 image/image-block 节点）、`findLinkRangeFromAnchor`（posAtDOM 定位 mark 范围）、`applyLinkHref`（removeMark+addMark，保留链接内其他 mark）、`applyImageSrc`（setNodeMarkup）、`refreshProxiedImageSources`（文档遍历，将 latestImages 映射写入 img DOM src）。
- `src/provider.ts`：`applyWebviewChange` 成功 `applyEdit` 后追加 `postDocumentUpdate(state)`，回传重算的 images 映射。
- `src/webview/style.css`：操作条样式（editorWidget 主题变量，与 block-insert-menu 一致）。

## 已知问题（既有，未在本需求修改）

- Crepe image-block 解析时把图片 alt 当缩放比例（非数字→1），序列化写回 `![1.00](src)`：任何编辑往返都会丢失图片 alt 文本（`@milkdown/components` image-block schema 仅 src/caption/ratio 三个属性）。后续需求可考虑覆写该 schema 的 parse/toMarkdown 以保留 alt。
