# 表格边框与 Crepe 主题变量修复

## 问题

暗色主题下表格完全看不到边框。根因：Crepe 结构样式（table.css 等）大量引用 `--crepe-color-*` 主题变量，但插件只引入了 `@milkdown/crepe/theme/common/style.css` 结构样式，未定义任何配色变量。表格单元格边框使用 `color-mix(in srgb, var(--crepe-color-outline), transparent 80%)`，变量未定义导致整条 border 声明失效（border-style: none），任何主题下表格都无边框；块手柄、单元格控件等其余 crepe 组件的配色同样处于未定义状态。

## 需求

- 在 Webview 样式中定义结构样式引用的全部 `--crepe-*` 变量（配色、字体、阴影），统一映射到 VS Code 主题变量，明暗主题自适应。
- 表格单元格边框加强为清晰可见（基于编辑器前景色调配），表头加浅色底，明暗主题均可辨识。
- 不引入 Crepe 官方配色文件，避免米色系配色与 VS Code 画布冲突。

## 验收标准

- 明暗主题下表格边框和表头底色清晰可见，样式随 VS Code 主题变化。
- Crepe 组件（单元格拖拽手柄、加号按钮等）配色正常，不再依赖未定义变量。
- `pnpm run check`、`pnpm run package` 和 `git diff --check` 通过。
