# 图表预览错误处理优化

## 问题

编辑模式实时预览在输入过程中频繁出现 “Syntax error in text / mermaid version 11.17.2”：渲染防抖仅 250ms，输入停顿超过该时间即用尚未写完的源码调用 Mermaid 解析并失败，错误文本整体替换预览区，严重干扰编辑。经运行时验证（浏览器 harness 对示例文档 34 个 mermaid 块逐个 `mermaid.parse`），全部图表类型在 Mermaid 11.17.2 中均可解析（`usecase-beta` 由插件翻译器兜底），该问题与图表数量和类型支持无关，来源是编辑过程中的中间态源码。

## 需求

- 渲染失败时保留上一次成功的预览，不整体替换为错误文本。
- 在预览下方显示一条错误状态条：按错误消息分类提示（不支持类型 / 语法有误），悬停可查看原始错误首行；渲染成功后自动消失。
- 编辑模式正在编辑的图表渲染防抖提高到 800ms，且每次输入重置计时（真防抖），连续输入不触发渲染；外部变更保持 250ms。
- 首次渲染即失败（无旧图）时同样使用状态条说明原因，不显示大段错误。

## 验收标准

- 编辑图表源码过程中预览不闪烁错误文本；停顿约 0.8 秒后按当前源码更新。
- 源码暂时无效时旧图表保持可见，预览下方出现语法有误提示；改回有效语法后提示消失、预览更新。
- 不支持的图表类型显示“当前 Mermaid 版本不支持该图表类型”。
- `pnpm run check`、`pnpm run package` 和 `git diff --check` 通过。
