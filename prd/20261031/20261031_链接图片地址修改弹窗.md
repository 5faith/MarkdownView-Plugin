# 链接图片地址修改弹窗

## 需求

编辑模式点击链接/图片弹出的地址弹窗改为 Typora 风格（参考图1）：左侧类型图标 + 地址文本 + 铅笔（修改地址）+ 垃圾桶（删除），替代此前「编辑/打开/移除」文字按钮形态。链接垃圾桶=移除链接标记（保留文本），图片垃圾桶=删除图片节点。

## 需求说明

- 弹窗结构：`[类型图标(svg)] [地址文本] [铅笔按钮] [垃圾桶按钮]`；链接显示 href，图片显示原始 src（读 PM 节点属性）。
- 铅笔：打开预填地址的输入对话框（沿用 `requestValue` 校验回调：相对路径放行、http/https 校验 host 拒绝环回/私有/保留地址、其他 scheme 拒绝），确认后链接走 `removeMark+addMark`，图片走 `setNodeMarkup`。
- 垃圾桶：链接 → 定位 `<a>` 的 mark 范围 `removeMark`；图片 → `tr.delete(pos, pos+nodeSize)` 删除 `image`/`image-block` 节点。
- 不设「打开」按钮：Ctrl/Cmd+点击跳转、只读模式点击直接跳转保持现状。
- 隐藏时机不变：点外部/Escape/滚动/切模式/宿主更新。

## 验收标准

- 点击链接/图片出现图1 形态弹窗，图标随类型切换。
- 铅笔修改链接 href / 图片 src 回写正确；垃圾桶移除链接（文本保留）或删除图片节点（回写 markdown 不再包含）。
- `git diff --check` 通过。
