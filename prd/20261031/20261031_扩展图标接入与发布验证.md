# 扩展图标接入与 PUBLISH.md 发布验证

## 需求

按 PUBLISH.md 对项目做发布前验证；插件图标使用 `src/assets/style3-dark-app-icon.ico`（多分辨率 ICO，16–256 共 6 帧 PNG 帧）。

## 需求说明

- 图标需位于 VSIX 打包路径内：`.vscodeignore` 排除了 `src/**`，因此复制到根路径 `assets/style3-dark-app-icon.ico`，并在 `package.json` 增加 `"icon": "assets/style3-dark-app-icon.ico"`。
- 按 PUBLISH.md 清单执行：`pnpm run check`、`pnpm run package`、`vsce ls`、VSIX 清单核对（publisher/repository/engines/license/description、README 相对图片、icon 注册）。

## 验收标准

- VSIX 内包含图标，`extension.vsixmanifest` 含 `<Icon>` 与 `Microsoft.VisualStudio.Services.Icons.Default` 资产。
- 类型检查与打包通过，无新增打包告警；`git diff --check` 通过。
