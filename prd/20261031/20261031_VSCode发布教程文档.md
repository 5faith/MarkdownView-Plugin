# VS Code 发布教程文档

## 需求

在仓库根路径提供面向维护者的 VS Code 扩展发布教程（PUBLISH.md），覆盖 Marketplace 发布者与 PAT 准备、发布前检查清单、打包与本地验证、`vsce publish` 发布、Open VSX 可选发布、常见问题与本项目命令速查，并结合本项目的实际构建方式（pnpm、esbuild 预打包、`--no-dependencies`）给出对应命令。

## 验收标准

- 根路径存在 PUBLISH.md，步骤可直接照做（命令与 package.json 脚本、发布者 ID 一致）。
- `git diff --check` 通过。
