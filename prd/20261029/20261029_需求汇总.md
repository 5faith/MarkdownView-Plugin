# markdown扩展语法

## 需求说明

## 需求

在 VS Code MarkdownView 画布中补齐 Markdown 功能点总结和本地样例中的内容能力。

## 功能范围

1. 图片支持相对路径、本地文件路径和远程 URL；Markdown 源文中的图片路径保持不变。
2. 支持 `<details>` / `<summary>` 折叠内容，并保留折叠标题和内容。
3. 支持 `> [!NOTE]`、`TIP`、`IMPORTANT`、`WARNING`、`CAUTION` 告警块。
4. 支持 CommonMark 定义列表语法，包含同一术语的多个定义。
5. 支持 ` ```mermaid ` 围栏图表；画布渲染图表，Markdown 源文仍保存 Mermaid 代码。

## 验收标准

- 示例中的五类内容在 Webview 中正确显示。
- 编辑和宿主文档更新不会丢失上述内容的语法及 Mermaid 源代码。
- 图片相对路径经宿主资源映射显示，远程图片 URL 可直接加载。
- `pnpm run check`、`pnpm run compile` 和 `pnpm run package` 通过。

# webview按需分包

## 需求说明

## 需求

减少 MarkdownView 初次加载 Webview 的 JavaScript 体积，避免在没有 Mermaid 图表的文档中下载 Mermaid 引擎。

## 实现约束

- Mermaid 模块仅在画布包含 Mermaid 节点时动态加载。
- Webview 以 ES module 分块构建并启用压缩，延续 nonce CSP 和 Webview URI 资源边界。
- VSIX 仍包含运行时所需的 Webview 分块。

## 验收标准

- `dist/webview.js` 显著小于引入 Mermaid 之后的 12.92 MB 基线。
- Mermaid 图表仍可按需加载、渲染；常规 Markdown 不依赖 Mermaid chunk。
- 类型检查、编译和 VSIX 打包通过。

## 修改记录

## 2026-10-29 — 减少 Webview 初始脚本体积

- Mermaid 构建为独立压缩运行时脚本，仅含 Mermaid 图表的文档才会加载。
- 主 Webview bundle 启用压缩，保持单个 nonce 脚本入口，避免大量运行时 chunk 请求。
- 通过受限的 Webview URI 加载 Mermaid 运行时，沿用 nonce CSP 和本地资源边界。

# 修复Markdown内容显示

## 需求说明

## 问题

本地 Markdown 测试文档中的图片只作为围栏代码示例，导致没有实际图片可渲染；画布禁用了 Crepe Latex 功能；文本选区缺少适配 VS Code 的高亮颜色；Mermaid 围栏可能被普通代码块节点优先识别。

## 需求

1. 在编辑画布中清晰显示鼠标选择的文本。
2. 让真实图片 Markdown 渲染本地相对路径图片，并支持 URL 图片。
3. 启用行内和块级数学公式渲染。
4. 确保 Mermaid 围栏被识别为图表节点，并按需渲染 Mermaid SVG。

## 验收标准

- 示例图片语法不处于代码围栏内，本地图片资源存在。
- 编辑/只读画布中选择文本时有明显选区背景。
- 行内和块级 LaTeX 内容经过 Crepe Latex 功能处理。
- Mermaid 代码块不会退化为普通代码块，并显示 Mermaid 图或可见的渲染错误。
- `pnpm run check`、`pnpm run compile` 和 `pnpm run package` 通过。
