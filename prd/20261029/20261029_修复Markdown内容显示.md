# 修复 Markdown 内容显示

## 问题

本地 Markdown 测试文档中的图片只作为围栏代码示例，导致没有实际图片可渲染；画布禁用了 Crepe Latex 功能；文本选区缺少适配 VS Code 的高亮颜色；Mermaid 围栏可能被普通代码块节点优先识别。

## 需求

1. 在编辑画布中清晰显示鼠标选择的文本。
2. 让真实图片 Markdown 渲染本地相对路径图片，并支持 URL 图片。
3. 启用行内和块级数学公式渲染。
4. 确保 Mermaid 围栏被识别为图表节点，并按需渲染 Mermaid SVG。

## 验收标准

- 示例图片语法不处于代码围栏内，本地图片资源存在。
- 编辑/只读画布中选择文本时有明显选区背景。
- 行内和块级 LaTeX 内容经过 Crepe Latex 功能处理。
- Mermaid 代码块不会退化为普通代码块，并显示 Mermaid 图或可见的渲染错误。
- `pnpm run check`、`pnpm run compile` 和 `pnpm run package` 通过。
