# Mermaid 用例图兼容

## 问题

本地 Mermaid 版本未注册 `usecase-beta` 图表解析器，导致示例用例图显示 “No diagram type detected”。

## 需求

- 保留 `usecase-beta` Markdown 源语法不变。
- 在 Webview 渲染时将 actor、use case 和 `-->` 关联转换为当前 Mermaid 版本支持的图表语法。
- 对重复标识符、未知关联端点和不支持的声明显示明确的图表错误。

## 验收标准

- `examples/local-test.md` 中的用户、管理员和三个用例以及关联均能生成流程图输入。
- Mermaid 转换仅作用于 `usecase-beta`，其他 Mermaid 图表源码保持原样。
- 转换规则测试、类型检查和插件打包通过。
