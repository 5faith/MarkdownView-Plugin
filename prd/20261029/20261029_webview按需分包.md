# Webview 按需分包

## 需求

减少 MarkdownView 初次加载 Webview 的 JavaScript 体积，避免在没有 Mermaid 图表的文档中下载 Mermaid 引擎。

## 实现约束

- Mermaid 模块仅在画布包含 Mermaid 节点时动态加载。
- Webview 以 ES module 分块构建并启用压缩，延续 nonce CSP 和 Webview URI 资源边界。
- VSIX 仍包含运行时所需的 Webview 分块。

## 验收标准

- `dist/webview.js` 显著小于引入 Mermaid 之后的 12.92 MB 基线。
- Mermaid 图表仍可按需加载、渲染；常规 Markdown 不依赖 Mermaid chunk。
- 类型检查、编译和 VSIX 打包通过。
