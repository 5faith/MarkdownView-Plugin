# Markdown 扩展语法支持

## 需求

在 VS Code MarkdownView 画布中补齐 Markdown 功能点总结和本地样例中的内容能力。

## 功能范围

1. 图片支持相对路径、本地文件路径和远程 URL；Markdown 源文中的图片路径保持不变。
2. 支持 `<details>` / `<summary>` 折叠内容，并保留折叠标题和内容。
3. 支持 `> [!NOTE]`、`TIP`、`IMPORTANT`、`WARNING`、`CAUTION` 告警块。
4. 支持 CommonMark 定义列表语法，包含同一术语的多个定义。
5. 支持 ` ```mermaid ` 围栏图表；画布渲染图表，Markdown 源文仍保存 Mermaid 代码。

## 验收标准

- 示例中的五类内容在 Webview 中正确显示。
- 编辑和宿主文档更新不会丢失上述内容的语法及 Mermaid 源代码。
- 图片相对路径经宿主资源映射显示，远程图片 URL 可直接加载。
- `pnpm run check`、`pnpm run compile` 和 `pnpm run package` 通过。
