# 修改记录：编辑模式图表即时预览

## 2026-10-30 — 编辑模式 Mermaid 改为即时预览视图

- 重写 Mermaid NodeView 的面板状态：以“源码面板是否展开”与“预览是否可见”两个状态替代 `showingSource`/`renderRequested` 等交叉标志，编辑模式默认仅显示渲染预览，不再默认展开源码面板。
- 编辑模式右下角按钮改为“源码”/“收起源码”，控制可编辑源码面板的展开与折叠，预览始终可见；只读模式保留“源码”/“图表”切换，并在返回预览时按需补渲染。
- 节点更新仅在源码变化时以约 250ms 防抖重渲染；渲染期间保留旧预览，不再把占位文本写回已渲染的预览；渲染失败时保留已有 SVG 并在其下追加错误信息，避免编辑过程中预览闪现占位或被清空。
- 模式切换与节点内容更新不再强制改变源码面板展开状态；源码为空时编辑模式自动展开源码面板并显示“暂无图表源码”提示。
- 图表块 DOM 顺序调整为预览在前、源码面板与按钮在后；监听 `<summary>` 原生折叠事件同步面板状态，占位与提示文案改为中文；移除不再使用的 focusin 强制展开与辅助判断函数。
- 更新 README 与 `examples/local-test.md` 中编辑模式图表行为说明。

## 2026-10-31 — 移除图表右下角源码按钮

- 图表底部“Mermaid 源码”折叠标题已承担展开/折叠功能，移除右下角“源码/图表/收起源码”按钮及 controls 容器，源码面板统一通过 `<details>` 原生 toggle 事件同步预览显隐与只读模式补渲染。
- 清理 style.css 中不再使用的 `.mermaid-diagram-controls` 与 `.mermaid-diagram-render` 样式。
- 同步更新需求文档、README 与示例文档中的图表切换说明。

## 2026-10-31 — 修复图表停留占位不渲染

- 编辑模式（含只读）下图表停留在“图表将在滚动到可视区域后渲染”占位：IntersectionObserver 可视区域门控在 Webview 中未触发，且“等可视区域再渲染”与即时预览需求相悖。
- 移除 IntersectionObserver 门控：节点创建和源码变化后立即渲染预览（源码编辑仍 250ms 防抖、渲染期间保留旧预览）；Mermaid 运行时改为首次渲染时按需加载一次。
- 同步更新需求文档与 README、示例中“滚动到可视区域后渲染”的表述。

## 2026-10-31 — 图表渲染队列与可视区调度（修复多图表卡死）

- 全部图表即时渲染导致多图表文档（示例约 30 张）在编辑模式卡死：进入编辑或宿主更新会重建节点视图，所有 Mermaid 渲染同时压上主线程，且 `mermaid.initialize` 每次渲染都重复执行。
- 恢复可视区域渲染，但改用确定性位置检查：节点创建、源码变化（250ms 防抖后）、模式切换、文档滚动和窗口缩放时用 `getBoundingClientRect` 判断图表是否在视口附近（200px 预加载），替代未可靠触发的 IntersectionObserver，避免占位滞留。
- 新增全局串行渲染队列：请求逐个出队、帧间让出主线程，渲染不再批量阻塞；视图销毁或源码变化时取消未完成的请求。
- 新增按“主题 + 源码”的 SVG 渲染缓存（上限 60 条，LRU）：模式切换、文档重建等未变更图表直接复用缓存瞬间显示；`mermaid.initialize` 按主题仅执行一次，主题切换时重置。
- 同步更新需求文档与 README、示例说明。
