# 修改记录：源码模式恢复性能优化

## 2026-10-30 — 优化源码切回富文本的恢复性能

- 增加安全 Markdown 块拆分器；无法保证块间语义独立时拒绝拆分并使用完整解析。
- 单个段落或标题变更时替换对应 ProseMirror 节点；多块安全内容分批解析和提交，每批最多 3 个块，并在批次间让出浏览器帧。
- 抑制源码恢复事务触发的中间文档同步，避免不完整内容写回 VS Code；遇到解析失败或不安全结构时回退到完整文档解析。
- 记录增量、分批、完整解析的耗时，以及 Mermaid 图表渲染耗时。
- Mermaid 节点通过 `IntersectionObserver` 延迟加载和渲染；屏外更新保留待渲染状态，不支持观察器的环境继续立即渲染。
- 更新 README 说明优化策略和回退边界。
