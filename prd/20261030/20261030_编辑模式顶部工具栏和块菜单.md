# 编辑模式顶部工具栏和块菜单

## 需求

编辑模式下，在编辑器顶部提供常用 Markdown 格式操作，顺序为：标题、加粗、斜体、删除线、行内代码、水平线、引用、列表（无序、有序、任务、定义）、表格、代码块、折叠块、图片和链接。

恢复 Milkdown Crepe 默认的块编辑加号菜单，允许从块插入菜单创建文本、标题和其他支持的块。

## 验收标准

- 顶部格式工具栏只在编辑模式显示，切换到只读模式后隐藏。
- 工具栏命令作用于当前光标或选区，并通过 Milkdown 文档同步到 VS Code。
- 列表下拉菜单提供无序、有序、任务和定义列表。
- 图片和链接可以输入地址；可选输入图片说明。
- Crepe 的块编辑加号菜单在可编辑状态可用。
- 通过类型检查和扩展打包。
