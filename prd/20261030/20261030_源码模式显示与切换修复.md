# 源码模式显示与切换修复

## 需求

- 源码模式以无边框、无输入框外观的常规编辑画布显示 Markdown 内容。
- 从源码模式切换到只读或编辑模式时，正确同步源码内容并切换到对应视图，不应停留在源码模式。
- 未修改源码时，离开源码模式不得重复解析并重建 Milkdown 文档；修改过时先完成目标模式绘制，再解析并更新富文本画布。

## 验收标准

- 源码区域没有边框、圆角或单独输入框背景，内容仍可正常编辑和滚动。
- 从源码模式分别切换到只读和编辑模式均成功，内容保持一致；编辑模式工具栏显示，未保存源码内容同步到 VS Code 文档。
- 源码未变化时切换不触发不必要的 Markdown 全量解析；源码有改动时显示目标模式后再应用内容。
- `pnpm run check`、`pnpm run package` 和 `git diff --check` 通过。
