# 三态模式与编辑区布局

## 需求

- 右上角模式控制提供只读、编辑、源码三种模式。
- 源码模式允许直接编辑 Markdown，并将修改同步到 VS Code 文本文档；切换模式时保留尚未提交的变更。
- 重新组织页面布局：左侧固定大纲，编辑工具栏和模式切换合并到工作区顶部，正文或源码位于其下方。
- 正文和源码编辑区占用大纲右侧的可用宽度，具有明确的最小宽度，并在窄视口下可横向滚动。

## 设计约束

- 保留 VS Code `TextDocument` 为持久化内容来源，不由 Webview 直接读写文件。
- 只读模式拒绝来自 Milkdown 和源码编辑框的文档更改。
- 正文与源码模式共用同一编辑区宽度规则：宽视口下占满大纲右侧的可用空间，最小宽度 40rem，不设置最大宽度；可用空间不足时保留最小宽度并允许横向滚动。
- 大纲在源码模式根据 Markdown 标题更新，并可定位到对应源码行。

## 验收标准

- 三种模式切换状态准确；编辑和源码修改同步为 VS Code 文档编辑。
- 源码切换到所见即所得后显示相同内容，修改不会因切换而丢失。
- 编辑工具栏仅在编辑模式显示，所有模式按钮集中于同一顶部栏。
- 大纲、编辑区和工具栏布局一致；正文与源码区均占满可用空间，且在窄视口下保留最小宽度。
- `pnpm run check` 和 `pnpm run package` 通过。
