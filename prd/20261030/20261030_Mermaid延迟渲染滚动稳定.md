# Mermaid 延迟渲染滚动稳定

## 问题

Mermaid 图表进入可视区域后异步加载 SVG。预览区域高度从占位内容变为图表高度时，浏览器滚动锚定可能改变页面滚动位置，导致视口持续跳向文档底部。

## 需求

- Mermaid 加载期间保留当前图表预览或占位内容，避免先清空预览造成高度塌陷。
- SVG 或渲染错误内容写入时保留 Webview 当前滚动坐标，避免滚动锚定将视口移动到文档底部。
- 不影响图表进入可视区域后延迟加载的行为，也不改变用户主动滚动。

## 验收标准

- 在图表上方、图表处或文档底部滚动时，异步加载 Mermaid 图表不会把视口跳到底部。
- 源码未变化的图表仍保留已有预览，不重复渲染。
- Mermaid 成功及失败结果写入预览时均保持页面滚动坐标稳定。
- `pnpm run check`、`pnpm run package` 和 `git diff --check` 通过。
