# 源码切回富文本加载指示

## 需求

- 从源码模式切回只读或编辑模式且源码有变更时，在 Markdown 重新解析期间显示加载动画和状态提示。
- 目标模式及加载提示应在同步解析开始前完成绘制；富文本更新完成并完成一次绘制后移除提示并恢复交互。
- 源码未变化的切换继续跳过解析和加载提示。

## 验收标准

- 修改源码后切换模式，富文本区域显示带旋转动画的加载状态，解析完成后自动关闭。
- 未修改源码时模式切换不出现加载状态。
- 加载提示跟随 VS Code 主题，且不遮挡大纲和顶部模式控制。
- `pnpm run check`、`pnpm run package` 和 `git diff --check` 通过。
