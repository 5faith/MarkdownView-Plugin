# Mermaid延迟渲染滚动稳定

## 需求说明

## 问题

Mermaid 图表进入可视区域后异步加载 SVG。预览区域高度从占位内容变为图表高度时，浏览器滚动锚定可能改变页面滚动位置，导致视口持续跳向文档底部。

## 需求

- Mermaid 加载期间保留当前图表预览或占位内容，避免先清空预览造成高度塌陷。
- SVG 或渲染错误内容写入时保留 Webview 当前滚动坐标，避免滚动锚定将视口移动到文档底部。
- 不影响图表进入可视区域后延迟加载的行为，也不改变用户主动滚动。

## 验收标准

- 在图表上方、图表处或文档底部滚动时，异步加载 Mermaid 图表不会把视口跳到底部。
- 源码未变化的图表仍保留已有预览，不重复渲染。
- Mermaid 成功及失败结果写入预览时均保持页面滚动坐标稳定。
- `pnpm run check`、`pnpm run package` 和 `git diff --check` 通过。

## 修改记录

## 2026-10-30 — 保持图表异步加载时的视口位置

- Mermaid 节点开始异步渲染时保留现有预览；初次渲染时继续显示占位，成功后再替换，避免先清空内容造成高度塌陷。
- 不在异步渲染完成时恢复过期的 `scrollTop`，避免覆盖用户加载期间的滚动操作。
- 保留浏览器默认滚动锚定，让文档自身处理图表高度变化。

## 验证

- `pnpm run check`
- `pnpm run package`
- `git diff --check`

# 源码模式恢复性能优化

## 需求说明

## 需求

- 源码模式修改内容后切回富文本时，减少主线程一次性解析和更新大文档造成的卡顿。
- 仅在文档结构安全且语义保持一致时采用增量或分批解析；无法安全拆分时保留完整文档解析。
- Mermaid 运行时及图表延迟到图表进入可视区域后加载和渲染；屏外节点更新后，在重新可见时渲染最新内容。
- 在开发者控制台记录富文本恢复策略、解析与应用耗时，以及 Mermaid 图表渲染耗时，便于定位性能问题。

## 实现约束

- 单个安全段落或标题的变更可直接替换对应 ProseMirror 节点。
- 多个安全 Markdown 块分批解析和提交，每批不超过 3 个块，并在批次间让出一帧。
- 引用链接等依赖全文上下文的语法，以及不支持的复杂块结构，不得分块解析，必须走完整解析以保持 Markdown 语义。
- 源码恢复期间的中间 ProseMirror 更新不得同步回 VS Code 文本文档。
- 若浏览器不支持 `IntersectionObserver`，Mermaid 图表应立即渲染，保证兼容性。

## 验收标准

- 类型检查、扩展打包和 `git diff --check` 通过。
- 单块安全编辑使用增量更新；多个安全块分批更新；无法安全拆分时完整解析。
- 分批解析期间不会将不完整内容写回 VS Code 文本文档。
- 屏外 Mermaid 图表不加载运行时；进入可视区域后加载和渲染，且源码仍可查看。

## 修改记录

## 2026-10-30 — 优化源码切回富文本的恢复性能

- 增加安全 Markdown 块拆分器；无法保证块间语义独立时拒绝拆分并使用完整解析。
- 单个段落或标题变更时替换对应 ProseMirror 节点；多块安全内容分批解析和提交，每批最多 3 个块，并在批次间让出浏览器帧。
- 抑制源码恢复事务触发的中间文档同步，避免不完整内容写回 VS Code；遇到解析失败或不安全结构时回退到完整文档解析。
- 记录增量、分批、完整解析的耗时，以及 Mermaid 图表渲染耗时。
- Mermaid 节点通过 `IntersectionObserver` 延迟加载和渲染；屏外更新保留待渲染状态，不支持观察器的环境继续立即渲染。
- 更新 README 说明优化策略和回退边界。

# 编辑模式图表即时预览

## 需求说明

## 问题

编辑模式下 Mermaid 图表默认同时展开源码面板和渲染预览，图表块高度成倍增加，画布被源码占据；右下角按钮在编辑模式初始显示“图表”，与已可见的预览语义不符；源码面板会在节点内容更新或聚焦时被强制展开，用户收起后的状态无法保持。

## 需求

- 视口附近（含 200px 预加载范围）的图表在节点创建或源码变化后立即渲染；屏外图表在滚动接近时渲染。使用确定性的位置检查（创建、模式切换、滚动、缩放触发）代替 IntersectionObserver，避免占位滞留。
- 多图表文档的渲染进入全局串行队列，逐帧执行不阻塞输入与滚动；请求在视图销毁或源码变化时取消；相同主题与源码的渲染结果复用缓存；mermaid.initialize 按主题仅执行一次。
- 图表底部提供“Mermaid 源码”折叠标题，点击展开可编辑源码面板，再次点击折叠面板恢复纯预览；不提供额外的右下角按钮。
- 源码面板展开时编辑源码，预览保持显示，并以约 250ms 防抖即时更新；渲染失败时保留已有预览并在下方显示错误信息。
- 模式切换和节点内容更新不得强制改变源码面板展开状态；源码为空时编辑模式自动展开源码面板便于输入。
- 只读模式通过同一折叠标题在源码与预览间切换：查看源码时隐藏预览，返回预览时按需补渲染。
- Mermaid 运行时在首次渲染时按需加载一次；渲染期间保留旧预览，保持滚动位置稳定。

## 验收标准

- 打开文档或切换到编辑模式后，视口内图表直接显示渲染结果，不再默认展开源码面板。
- 打开示例文档（30+ 图表）并滚动浏览、输入文字，编辑模式下无明显卡顿。
- 点击“Mermaid 源码”折叠标题展开面板并修改源码，预览在短暂防抖后更新，且不会闪现占位或清空；图表块内不再出现右下角按钮。
- 渲染失败时预览不清空，错误信息出现在图表下方。
- 收起源码面板、切换模式或编辑文档其他内容后，面板状态保持不变。
- 空图表在编辑模式下自动展开源码面板。
- `pnpm run check`、`pnpm run package` 和 `git diff --check` 通过。

# 编辑模式恢复渲染与滚动修复

## 需求说明

## 问题

- 源码修改后切回编辑模式，编辑器恢复完成时焦点可能跳到文档末尾，导致用户滚动时位置异常。
- Mermaid 节点在编辑器事务中即使源码没有变化也会清空预览并重复渲染，可能表现为图表一直加载。

## 需求

- 模式切换聚焦编辑器时不得自动滚动页面或文档。
- Mermaid 节点内容未变化时保留已有预览，不重复渲染。
- Mermaid 图表接近可视区域时开始渲染；节点内容改变时仅在可见/接近可见后更新预览。

## 验收标准

- 从源码切到编辑模式后，视口不跳到文档末尾，编辑器仍可直接输入。
- 编辑或滚动经过未修改的 Mermaid 图表时，图表保持已渲染状态。
- 更新 Mermaid 源码后，图表预览能更新；可视区域外的图表在接近视口后能加载。
- `pnpm run check`、`pnpm run package` 和 `git diff --check` 通过。
