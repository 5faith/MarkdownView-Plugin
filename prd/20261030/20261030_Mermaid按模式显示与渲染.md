# Mermaid 按模式显示与渲染

## 需求

- 只读模式自动渲染 Mermaid 图表，包括流程图等常见 Mermaid 图表；图表仍按可见区域延迟加载。
- 编辑模式自动渲染所有 Mermaid 图表类型，包括流程图、时序图、脑图等。
- Mermaid 图表右下角提供“源码”/“图表”按钮，在源码和渲染预览之间切换；源码视图可在编辑模式下直接修改。
- 所有图表在编辑模式下同时显示预览和可编辑源码；源码输入后以短防抖即时更新预览。
- Mermaid 图表右下角提供“源码”/“图表”按钮，可折叠/展开源码面板，预览保持可见。
- 模式切换时不丢失 Mermaid 源码，图表源码仍由 Milkdown 正常编辑和序列化。

## 验收标准

- 只读模式进入图表可视区域后自动显示渲染结果。
- 编辑模式下所有 Mermaid 图表预览和源码同时可见；修改源码后预览在短暂防抖后更新。
- 图表右下角按钮能在源码和图表预览之间切换。
- 编辑/只读模式切换不丢失或改写 Mermaid 源码。
- `pnpm run check`、`pnpm run package` 和 `git diff --check` 通过。
