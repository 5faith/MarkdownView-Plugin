# 编辑模式图表即时预览

## 问题

编辑模式下 Mermaid 图表默认同时展开源码面板和渲染预览，图表块高度成倍增加，画布被源码占据；右下角按钮在编辑模式初始显示“图表”，与已可见的预览语义不符；源码面板会在节点内容更新或聚焦时被强制展开，用户收起后的状态无法保持。

## 需求

- 视口附近（含 200px 预加载范围）的图表在节点创建或源码变化后立即渲染；屏外图表在滚动接近时渲染。使用确定性的位置检查（创建、模式切换、滚动、缩放触发）代替 IntersectionObserver，避免占位滞留。
- 多图表文档的渲染进入全局串行队列，逐帧执行不阻塞输入与滚动；请求在视图销毁或源码变化时取消；相同主题与源码的渲染结果复用缓存；mermaid.initialize 按主题仅执行一次。
- 图表底部提供“Mermaid 源码”折叠标题，点击展开可编辑源码面板，再次点击折叠面板恢复纯预览；不提供额外的右下角按钮。
- 源码面板展开时编辑源码，预览保持显示，并以约 250ms 防抖即时更新；渲染失败时保留已有预览并在下方显示错误信息。
- 模式切换和节点内容更新不得强制改变源码面板展开状态；源码为空时编辑模式自动展开源码面板便于输入。
- 只读模式通过同一折叠标题在源码与预览间切换：查看源码时隐藏预览，返回预览时按需补渲染。
- Mermaid 运行时在首次渲染时按需加载一次；渲染期间保留旧预览，保持滚动位置稳定。

## 验收标准

- 打开文档或切换到编辑模式后，视口内图表直接显示渲染结果，不再默认展开源码面板。
- 打开示例文档（30+ 图表）并滚动浏览、输入文字，编辑模式下无明显卡顿。
- 点击“Mermaid 源码”折叠标题展开面板并修改源码，预览在短暂防抖后更新，且不会闪现占位或清空；图表块内不再出现右下角按钮。
- 渲染失败时预览不清空，错误信息出现在图表下方。
- 收起源码面板、切换模式或编辑文档其他内容后，面板状态保持不变。
- 空图表在编辑模式下自动展开源码面板。
- `pnpm run check`、`pnpm run package` 和 `git diff --check` 通过。
