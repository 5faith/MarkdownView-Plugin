# 加号插入菜单与紧凑画布布局

## 需求

- 编辑模式下，点击 Milkdown 块手柄的加号应可靠打开块插入菜单，并可插入正文、标题、引用、列表、分隔线、表格、代码块和折叠块。
- 大纲、编辑工具栏和正文区域使用紧凑间距，降低大纲宽度与顶部栏高度；窄视口仍可自适应。
- 正文画布和源码编辑器均使用大纲右侧的可用宽度，最小宽度为 40rem，不设最大宽度；空间不足时保留最小宽度并允许横向滚动。

## 验收标准

- 编辑模式下点击块手柄加号可打开插入菜单；点击或键盘选择菜单项后在当前块后插入目标内容，菜单关闭后编辑器仍可继续操作；点击外部或按 Escape 可关闭菜单。
- 菜单不会超出视口，样式与当前 VS Code 主题协调。
- 正文和源码编辑器采用一致的可用宽度和最小宽度，窄视口下编辑区不收缩。
- 大纲、顶部栏及正文间距相较原布局收紧。
- `pnpm run check`、`pnpm run package` 和 `git diff --check` 通过。
