# 编辑模式恢复渲染与滚动修复

## 问题

- 源码修改后切回编辑模式，编辑器恢复完成时焦点可能跳到文档末尾，导致用户滚动时位置异常。
- Mermaid 节点在编辑器事务中即使源码没有变化也会清空预览并重复渲染，可能表现为图表一直加载。

## 需求

- 模式切换聚焦编辑器时不得自动滚动页面或文档。
- Mermaid 节点内容未变化时保留已有预览，不重复渲染。
- Mermaid 图表接近可视区域时开始渲染；节点内容改变时仅在可见/接近可见后更新预览。

## 验收标准

- 从源码切到编辑模式后，视口不跳到文档末尾，编辑器仍可直接输入。
- 编辑或滚动经过未修改的 Mermaid 图表时，图表保持已渲染状态。
- 更新 Mermaid 源码后，图表预览能更新；可视区域外的图表在接近视口后能加载。
- `pnpm run check`、`pnpm run package` 和 `git diff --check` 通过。
